# Lista de Tareas Basica

Aplicacion web sencilla pensada para que los estudiantes practiquen conceptos basicos de JavaScript mediante una lista de tareas.

## Objetivo
Aprender a manipular el DOM con JavaScript de forma simple y visible.

Con este proyecto los alumnos practican:

- Capturar texto desde un `input`
- Ejecutar funciones con eventos
- Crear elementos HTML desde JavaScript
- Agregar elementos a una lista
- Marcar tareas como completadas
- Eliminar tareas

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades actuales

- Agregar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Validar que no se agreguen tareas vacias

## Como usar la aplicacion

1. Abrir el archivo `index.html` en el navegador.
2. Escribir una tarea en el campo de texto.
3. Presionar el boton `Agregar`.
4. Hacer clic en una tarea para marcarla como completada.
5. Presionar `X` para eliminar una tarea.

## Proposito pedagogico
Este proyecto fue planteado para trabajar una primera practica de JavaScript.

No es necesario incluir caracteristicas avanzadas en esta etapa. La idea es que el estudiante comprenda primero:

- como seleccionar elementos del documento
- como responder a eventos
- como crear y eliminar nodos
- como cambiar clases CSS desde JavaScript
