## Objetivo
Crear una aplicación web simple que permita organizar tareas de forma fácil y rápida.

---

## Funcionalidades
- Agregar tareas
- Eliminar tareas
- Marcar tareas como completadas
- Guardar tareas automáticamente (localStorage)

---

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

---

## Cómo usar la aplicación
1. Abrir el archivo `index.html`
2. Escribir una tarea en el campo de texto
3. Presionar el botón **Agregar** o la tecla **Enter**
4. Hacer clic en una tarea para marcarla como completada
5. Presionar X para eliminar una tarea
